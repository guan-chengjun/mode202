# GLB 模型来源与许可

本项目的外部 GLB 模型均为实际下载的低面数模型，未使用光线追踪或物理仿真。

| 文件 | 模型 / 作者 | 许可 | 来源页面 |
| --- | --- | --- | --- |
| `heliostat-stand.glb` | Tripod / Quaternius | CC0 1.0 | <https://poly.pizza/m/sVTKUSz3m2> |
| `mirror-panel.glb` | Mirror / Poly by Google | CC-BY 3.0 | <https://poly.pizza/m/cjvm-bUFBAW> |
| `receiver-tower.glb` | Power Line Tower / Grab3D | CC0 1.0 | <https://grab3d.com/models/city/power-line-tower/> |
| `ground-base.glb` | Prototype Thin Platform / Grab3D | CC0 1.0 | <https://grab3d.com/models/buildings/proto-thin-platform/> |

CC-BY 3.0 模型的署名已在本文件和项目 README 中保留。运行时会替换镜面材质、统一缩放并将其接入方位角/俯仰角节点层级；模型原始几何与许可信息保持可追溯。
